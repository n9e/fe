# Discord 配置指南

通过 Discord 频道的 Webhook 发送告警。一个 Webhook 地址对应一个频道，地址填在通知规则里，所以同一个 Discord 媒介可以发到任意多个频道（和钉钉机器人的用法一致）。系统已内置一个名为 Discord 的媒介，一般无需新建。

## 创建 Webhook

1. 在 Discord 里打开 **Server Settings** → **Integrations** → **Webhooks**（需要服务器的 **Manage Webhooks** 权限）
2. 点 **New Webhook**，选择要接收告警的频道
3. 点 **Copy Webhook URL**，得到形如 `https://discord.com/api/webhooks/<id>/<token>` 的地址

## 在通知规则里填写

| 字段 | 说明 |
|---|---|
| Webhook 地址 | 上一步复制的地址。它本身就是凭证，通知记录里会掩码显示。其他规则填过的地址，点输入框就能直接选（只显示名称和掩码），选中后整组参数一起填回 |
| 名称 | 给这个地址起个好认的名字，通知记录和地址输入框的下拉里显示的都是它 |
| 发送到 | 普通频道选「频道」；Webhook 绑定的是论坛频道时，选「新建论坛帖子」（每次通知新建一个帖子）或「已有线程或论坛帖子」 |

「新建论坛帖子」对每条通知都新开一个帖子，重复通知和恢复也不例外。重复通知间隔较短时，想把同一类告警收在一处，用「已有线程或论坛帖子」。线程 ID 可以在 Discord 里打开 Developer Mode 后右键帖子复制；也可以直接用某次「新建论坛帖子」通知记录里的 message id，它就是那个帖子的 ID。

## 媒介里的设置（可选）

显示名称、头像地址、静默推送是所有规则共用的默认值；访问 Discord 需要代理时，在高级设置里填写代理。

## 常见问题

- **10015 Unknown Webhook**：Webhook 已被删除，请重新创建
- **50027 Invalid Webhook Token**：地址不完整或 Webhook 已重置
- **220001**：这是论坛频道，「发送到」需要选择新建论坛帖子或已有线程
- **220003**：不是论坛频道，不能选「新建论坛帖子」
- **10003 Unknown Channel**：线程 ID 不存在，或不在这个 Webhook 所在的频道下
- **连接超时**：夜莺服务端访问不到 Discord，在媒介的高级设置里填写代理
- **429**：触发限速，系统会按 Retry-After 自动重试
