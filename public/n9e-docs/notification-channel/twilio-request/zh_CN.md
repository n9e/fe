# Twilio 短信与语音电话

同一种 Twilio 媒介可以选择短信或语音模式。如需同时发送两种通知，请分别创建短信、语音两条媒介，在通知规则中分别引用。

## 账号和发送配置

- **Account SID / Auth Token**：Twilio 账号凭证，支持 `{{.变量名}}` 引用。
- **短信**：填写 Twilio 发送号码、字母数字 Sender ID，或 Messaging Service SID。接收人必须是手机号，不支持 WhatsApp 等其他消息渠道。
- **语音电话**：发送号码必须为 E.164 格式的 Twilio 号码；通过 `<Say>` 播报告警正文，无需另行托管 TwiML。
- **语音名称 / 播报语言**：默认为 `woman` / `en-US`，其他语言请在 Twilio 的语音与语言列表中选择匹配组合，并同时修改这两个字段。
- **代理 / 超时 / 重试**：可按网络环境设置。重试次数 0 表示不重试。

## 通知规则和模板

选择接收人或接收组，使用其个人信息里的手机号。号码必须带国家码，如 `+8613800138000`。发送前会检查所有号码，重复号码只发送一次。

选择 Twilio 消息模板，正文键为 `content`。短信和电话均使用纯文本，默认包含级别、触发或恢复状态、告警名、监控对象和触发值。正文要求 1–1600 个字符；语音经 XML 转义后的 TwiML 不得超过 4000 个字符。短信长度会影响分段和费用，建议保持简短。

## 测试与结果

测试窗口选择接收人或组，并选择触发或恢复事件。点击测试会实际提交短信或电话请求，请使用预期接收人。

成功表示 Twilio 已受理，会显示 Message SID 或 Call SID，并不代表短信已经送达或电话已经接通。最终状态请在 Twilio 控制台查看。多接收人的某个请求失败时，其他接收人仍会发送，并保留部分成功结果。

仅明确的 HTTP 429 拒绝会自动重试。网络超时、5xx 和响应不完整时不自动重发，以减少重复短信、重复电话和计费。账号权限、试用账号已验证号码及目标地区发送权限请按 Twilio 控制台提示配置。

参考：[短信 API](https://www.twilio.com/docs/messaging/api/message-resource)、[语音 API](https://www.twilio.com/docs/voice/api/call-resource)、[Say 语音与语言](https://www.twilio.com/docs/voice/twiml/say)。

新试用账号可能仅允许发送 Twilio 预置短信正文。完整的告警短信联调需要允许自定义正文的账号；语音试用虽支持 `<Say>`，仍受账号地区、接收人和 API 参数限制。参见 [Twilio 试用限制](https://www.twilio.com/docs/usage/trials)。
